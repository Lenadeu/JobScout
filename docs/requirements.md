# JobScout Requirements

## Problem Statement

Searching for suitable C#/.NET software developer positions in Germany can be time-consuming because relevant information is spread across company career pages, job platforms, and company websites.

JobScout helps organize companies in Germany that currently hire, or could potentially hire, C#/.NET developers. The app supports both open job positions and companies that may accept initiative applications.

## Target User

The primary user is an experienced C#/.NET software developer with a background in desktop applications, ASP.NET MVC, Entity Framework, MySQL.

The user is applying for suitable software developer positions in Germany and wants to manage the job search in a structured way.

## Project Goal

Build a portfolio-quality ASP.NET Core MVC application that demonstrates practical C# web development skills while also helping with a real job search.

The project should show skills relevant for C# developer roles in Germany, especially:

- C# and .NET;
- ASP.NET Core MVC;
- Entity Framework;
- MySQL;
- clean Git workflow;
- requirements engineering;
- simple, maintainable architecture;
- practical business-oriented application design.

## Initial MVP Scope

The first version should allow the user to:

- save companies;
- save company career page links;
- save open C#/.NET job position links;
- mark whether a company currently has open C#/.NET positions;
- mark whether initiative applications are possible;
- add notes about technologies used by the company;
- add notes about application status;
- track whether German or English appears to be required;
- view all saved companies in one list.

## Out of Scope for the First Version

The first version will not automatically scrape job websites.

The first version will not send applications automatically.

The first version will not store private CV files, cover letters, phone numbers, or sensitive personal data.

## Success Criteria

The MVP is successful when the user can create, update, and manage a structured list of companies that are relevant for C#/.NET job applications in Germany.

The project is also successful when it can be shown on GitHub as a clean portfolio project with understandable requirements, readable code, and a clear commit history.
